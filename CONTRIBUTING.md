# Contributing

This repository is private during peer review. Issue reports and code changes
are currently limited to the manuscript authors and approved collaborators.

Before opening a change:

- keep dataset files and checkpoints outside Git;
- include the random seed and exact command used for reported results;
- run `pytest -q`;
- document whether a result is manuscript-derived or independently reproduced;
- do not relabel third-party components as original D2ES-Net contributions.
